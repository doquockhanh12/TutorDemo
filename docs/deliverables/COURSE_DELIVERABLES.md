# Course Deliverables Checklist

Theo sheet đề tài, output cần nộp gồm:

- [ ] Requirement.
- [ ] User flow.
- [ ] Wireframe / UI design.
- [ ] GitHub repository.
- [ ] Slide.
- [ ] Demo URL.

Khuyến nghị thêm trong repo:

- [ ] README có hướng dẫn chạy.
- [ ] `.env.example`.
- [ ] Seed/demo account.
- [ ] Screenshot hoặc short demo GIF/video link.
- [ ] Known limitations.
