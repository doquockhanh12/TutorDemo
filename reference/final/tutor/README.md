# TutorNearMe — Tutor Homepage V1

Static HTML/CSS/JS prototype dành cho phía Gia sư, được thiết kế cùng visual family với Learner Homepage V2 nhưng khác hoàn toàn về nội dung và mục tiêu.

## File
- `index.html` — toàn bộ cấu trúc homepage Tutor
- `styles.css` — design system và responsive styles
- `script.js` — menu, matching filter, sort, calculator, schedule toggle và modal demo

## Vai trò của trang
Đây là **public Tutor homepage / tutor acquisition entry**, không phải Tutor Dashboard. Sau khi đăng nhập, người dùng mới chuyển sang workspace `/tutor/dashboard`.

## Hướng nội dung
1. Giá trị của việc làm gia sư
2. Matching theo môn/khu vực/lịch/mức phí
3. Yêu cầu học đang chờ
4. Quy trình tạo hồ sơ → mở lịch → nhận request → xây uy tín
5. Preview Tutor workspace dựa trên reference của project
6. Mô phỏng thu nhập (chỉ để hình dung, không phải cam kết)
7. Chất lượng hồ sơ
8. Câu chuyện/công cụ hỗ trợ gia sư
