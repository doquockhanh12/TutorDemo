# TutorNearMe Homepage

The main page now uses a more readable, vivid visual system inspired by the
hierarchy of the VUS homepage. TutorNearMe keeps its own copy, images and brand.

## Design

- Main content uses Nunito at a 16px reading size with comfortable line spacing.
- Headings use short, sentence-case messages and emphasize one key phrase.
- The search panel, shortcuts and learning-goal cards use strong blue, coral,
  yellow, green and violet surfaces.
- Header and footer markup and styling remain as before.

## Files

- `index.html`: content, heading emphasis and font loading
- `styles.css`: original layout and component styles
- `theme.css`: current typography and color treatment for the main page
- `script.js`: page interactions

Open `index.html` directly or use a local static server. Google Fonts and
Unsplash images require an Internet connection.
